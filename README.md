# Math 4083 Syllabus — Abstract Algebra, Fall 2026

Syllabus for Math 4083 (Abstract Algebra), section 001, Fall 2026, taught by
Dr. Blake Farman at Louisiana Tech University. Built with
[PreTeXt](https://pretextbook.org/documentation.html).

Textbook: *Algebra: Notes from the Underground*, 1st edition, by Paolo Aluffi. The course
covers rings, modules, and groups (roughly Chapters 1–5, 8, and 10–11), building on the
logic, set theory, and proof techniques from MATH 3073/3113.

Class meets MWF, September 11 – November 18, 2026. There is one midterm exam
(Wednesday, October 14) and a cumulative final exam (Wednesday, November 18). Grades are
weighted 50% quizzes, 25% midterm, 25% final; homework is assigned every class but ungraded.
